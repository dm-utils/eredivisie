# Eredivisie for Home Assistant

Live Eredivisie score, league position, and next/last match for your club —
via [football-data.org](https://www.football-data.org)'s free API (no
credit card). Fills a real gap: TeamTracker, the most popular HA sports
integration, doesn't natively support Eredivisie.

Status: early development — validating the API against a real pilot script
before building the full integration. See [DESIGN.md](DESIGN.md).
